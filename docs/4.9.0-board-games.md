# 4.9.0 棋类大礼包

新增“棋类”分类与六款游戏，游乐场从 23 款增至 29 款。Windows、离线网页与安卓的共用游戏统一为 4.9.0。

## 六款玩法

- **猪猪象棋**：按中国象棋走子，包含蹩马腿、塞象眼、炮架、过河兵、九宫与将帅照面限制。不能走出使己方将帅被攻击的棋；将死或无合法着法判负。休闲重复规则为同一局面第三次出现时，仅一方在这段中每步将军则该方判负，否则和棋；120 个半回合未吃子自动和棋。没有实现完整竞赛中的复杂长捉、兑献等裁决。
- **猪猪国际象棋**：包含王车易位、吃过路兵、后/车/象/马四种升变、将军、将死与逼和。三次重复和五十回合规则采用自动判和。点击升变选择框选取棋子。
- **猪猪五子棋**：默认 15 路、黑先，横、竖或斜线连成至少五子获胜；满盘仍无五连为和棋。默认没有连珠比赛中的黑方禁手。
- **猪猪黑白棋**：8×8 棋盘，落子必须在八个方向之一夹住对方棋子，夹住的棋子全部翻为己方。没有合法着法时自动跳过，双方均无路时数子，多者胜。
- **猪猪海战**：先手动或随机布置舰队，再轮流选择对方海域开炮。界面显示命中、落空与击沉，全部击沉对方舰队获胜。对手仅根据公开的开炮结果选点。同屏双人使用交接遮挡，交接完成再展示另一方海域；开炮后禁用悔棋，避免借此窥探隐藏信息。
- **猪猪围栏**：轮流在相邻点之间画一条边，围出完整格子得分并继续行动；一条边可以同时围住两格。全部格子归属后，得格多者获胜。

## 操作、电脑与续局

六款均支持三档电脑对手与同屏双人。人机可以选择先后手，象棋与国际象棋按玩家一侧调整棋盘朝向。点击或触屏选棋落子；可用方向键移动光标、Enter 确认，U 悔棋、H 提示。人机悔棋会退回到自己的行动；海战按上述隐藏信息规则限制悔棋。

每步自动保存当前棋类和难度下的对局，重新进入时可以“接着上一局”；终局会清除这份未完对局。认输需要两次确认。切换或悔棋会使过时的电脑计算结果失效。电脑优先在后台线程思考，线程不可用时自动改为前台计算；电脑定位为本地入门和练习对手，没有使用云端引擎。

棋子带猪耳朵、猪鼻或猪头造型，玩家自己的棋子跟随当前配色。走子、吃子、将军、五连、黑白棋翻面、围格、海战炮弹和沉没均有动画；界面尊重系统“减少动态效果”设置。

## 同步改进

音游使用独立谱面和判定核心，鼓点与落点旋律提前安排到音频时刻，加入四小节呼应、休止、长按暂停后重新接按及无音频设备兜底。修复黑猪8 侧栏图标缺失。安卓网页允许后台棋类线程。

## 验证范围

本地构建前已通过 16 组规则与联机回归。六款各一局人机和同屏双人，分别在源码页、离线 HTML 与 APK 内置网页的手机视口下进行真实点击检查，覆盖悔棋、提示、认输、续局及自然终局。Windows 4.9.0 实际程序已逐款检查电脑应答与后台线程。两 APK 的显示版本为 4.9.0，内部编号为 40910 / 40900，沿用原签名。

发布时另核对公开源码、离线 HTML、APK 内置网页及发行附件的内容一致性。安卓真机安装与触屏手感、Windows 7 实机、真人音效听感尚未验收。棋类后端接口和开源许可见 [开发说明](../desktop/docs/headless-games.md)。
