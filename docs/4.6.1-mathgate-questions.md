# 4.6.1 · 猪猪闯算门题目大升级

## 出题方式

门上的常数式子由 `gate-core.js` 的表达式树现场生成：先定答案 k，再由 `expand(k, budget, level)` 随机拆成 +、−、×、÷、分数、百分数、平方、根号，叶子再按难度换成乘方开方写法（`POW_FORMS`，14 种）或微积分 / 求和 / 组合 / 对数 / 复数写法（`CALC_FORMS`，42 种），每种写法的参数也随机。`flavour` 保证每档式子带本档的招牌运算（加减乘除必含乘除，平方开方必含乘方或根号，微积分必含微积分写法）。

n 门（`NOPS`，25 种）直接给出 n 的变化，例如 `n→(n+24)÷3`、`n→12√n`、`n→(x²−31x)′|ₓ₌ₙ`、`n→∫ₙ³ⁿ dx`，全部单调不减。

## 四档难度

| 难度 | 常数式子 | 颜色提示 | 跑速 / 门距 |
|---|---|---|---|
| 加减乘除 | 两三步四则混合，带括号、分数、百分数 | 蓝 / 红 | 9.5 / 30 |
| 平方开方 | 幂、根、分数与负指数、勾股数、平方差、根号乘除、多重根号 | 无 | 8.5 / 32 |
| 微积分 | 定积分、导数与二阶导、极限、求和、组合排列、对数 | 无 | 7 / 36 |
| 混合运算（新增） | 以上全部，另有复数的模与共轭相乘 | 无 | 7 / 36，9 排门 |

每排门有三种局面：两扇都变多但只差 5%–20%（约 45%）、一好一坏（约 43%）、两扇都变少（约 12%，前两排不出现）。同一局与最近 120 个题型会尽量避开。上方题卡放大显示下一排两扇门，过门后揭晓答案和另一扇门的结果。

猪王血量仍按“每扇门选结果更大的”最优路线设定，每一关一定有解。

## 测试

`test-gate.cjs` 共 330372 项检查：

- 每种写法都用独立的数值方法复算：定积分用 Simpson，导数用中心差分，极限取邻近点，求和逐项相加。
- 上万道随机式子按结构复算；不含微积分的式子再按屏幕显示的文字重新计算，确认括号和指数的写法无歧义。
- 25 种 n 门逐一对照独立公式，并在 0–999 上检查单调不减。
- 四档难度各 6 关：最优路线必胜、最差路线必败，结果与帧率无关。
- 下一关会主要使用上一关没出现过的写法。
