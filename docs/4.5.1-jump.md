# 4.5.1：猪猪跳一跳

第 20 款离线游戏，使用已有 PigArt / PigLook 角色、四套配色、表情和音效。画面使用几何台面，没有新增素材或模型。GitHub 参考的固定代码与完整许可见 [第三方说明](../THIRD_PARTY_NOTICES.md)。

## 规则

鼠标 / 手指按住画面或下方按钮，或按住空格 / Enter 蓄力。按得越久跳得越远，1.5 秒蓄满后等待松开，不自动起跳。方向自动瞄准下一平台；偏离中心的落点会保留，下一跳从实际位置出发。小蹄子是否落在方形或圆形台面内决定成功，不用猪猪肚子的视觉外框放大接触范围。

普通落台 +1 分，连续中心依次 +2、+4、+6、+8、+10，之后每次 +10。普通落台、落回原台和掉落打断连续中心；落回原台不加分，可以接着跳。经典挑战与轻松练习分别保存最高分，练习平台更宽、间距较近，蓄力时显示虚线落点圈。

暂停、弹窗、切出窗口、触摸取消和离开游戏会取消未释放的蓄力；已在空中的跳跃暂停后可以接着飞完。最高分每次成功落台便保存。
