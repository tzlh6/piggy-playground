# 4.7.3：书籍分级目录

猪猪爱学习选择资料时先只列书名。点击书名展开章节目录，再展开章节或节目录，选择课时、专题等具体练习。也能直接选择整本、整章或整节练习；综合试卷与练习收在单独的折叠目录，按整套选择。

当前选择显示完整目录路径，题数、题型、难度和实际出题都限制在所选范围。调整题型、难度或题数后保留目录展开状态。题库文件管理列表默认折叠。原书“例1”等题号保留。

题库格式兼容第1、2版。书籍文件在头部4096字符内提供 `book`、`chapter`、`topic` 元数据；同一学科同名书籍聚合，`topic` 用 ` · ` 分隔多级目录，也兼容“第3节…-课时1…”写法。书名、章节、课时分开存储，安卓导入到本地后仍能重建目录；没有书籍元数据的普通试卷按整套保留。旧版合并书籍文件仍可使用。

Windows、离线网页和安卓共用游戏均为4.7.3。Windows最低外壳版本仍为4.7.1。安卓普通包40713，旧更新器兼容包40703，沿用原签名，nativeRevision=5；覆盖安装保留题库、成绩与设置。安卓继续支持ZIP一次导入，也可导入JSON。

题库由使用者自行准备，个人题库、题图、答案及其压缩包不进公开仓库或发行附件。旧合并书籍与新分课时文件同时导入会重复计数，改用分课时文件时可在本机管理列表移除对应的旧合并题库，保留原文件。

验证包括目录分组与题数、跨学科同名书籍、节与课时展开、整本/整章/单课时范围、原例题标号、实际页面选题及解析显示，并执行既有游戏回归。安装包检查版本、签名和内置页面一致性。安卓真机安装、系统文件选择器及Windows 7实机尚未验收。
