# 4.7.1 · 猪猪爱学习

第 23 款游戏。眼镜猪老师用题库里的真题出题，玩家的小猪作答，答完显示原卷答案与解析。（4.7.0 只在本机构建、没有公开发布；首个公开版本是 4.7.1。）

## 玩法

- 上方选学科（全部 / 数学 / 物理 / 化学 / 生物 / 语文 / 英语），选课页再选套卷、题型、难度、题数（5 / 10 / 20）、模式（新题优先 / 错题重练）。
- **题型**按学科细分（`study-core.js` 的 `KINDS`）：数学 单选 / 多选 / 填空 / 解答；物理 单选 / 多选 / 实验 / 填空 / 计算；化学 选择 / 实验 / 工艺流程 / 反应原理 / 物质结构 / 有机 / 其他；生物 单选 / 不定项 / 遗传 / 实验探究 / 其他；语文 信息类 / 文学类 / 文言文 / 古代诗歌 / 名句默写 / 语言文字运用 / 写作；英语 阅读理解 / 七选五 / 完形填空 / 语法填空 / 阅读表达 / 应用文写作 / 读后续写 / 概要写作。“全部学科”用五大类（选择 / 填空 / 解答 / 阅读题组 / 写作）。分类依据题目所在大题标题、题干关键词与题组结构。
- **难度** 1–3（基础 / 中档 / 较难）：题库没有原卷难度标记，按同一单元同题型内的位置（前三分之一基础、后四分之一较难）和栏目（刷基础 / 刷提升 / 刷难关等）估计；竞赛卷都为较难；英语读后续写、语文文言文与诗歌为较难。
- **选择题**先选中（可改），点“交卷”或按 Enter 才判分。
- **数学填空**：输入框 + 符号键盘 + KaTeX 预览。`study-math.js` 把参考答案的 LaTeX 和玩家输入解析成同一种表达式树（数、π、e、i、变量与下标、四则、乘方、√ / root、ln / lg / log_b、三角与反三角、绝对值、阶乘、度；区间、并集、集合、方程、不等式、“或”并列答案），复数求值后在 8 组固定取值点比较；方程按两边之差成比例判等，单变量不等式化成区间。参考答案读不懂（“见解析”、分小问、文字结论）时改为看答案自评。判错时可“改判为对”。
- **英语语法填空**：输入单词或词组，忽略大小写和首尾标点；参考答案中“/”“或”分隔的写法都算对。
- **整篇阅读**（题库第 2 版的 `subs`）：选择小题点选；七选五用公共选项点字母；文言断句点出断开处的字母（每对一处得分，多选不得分）；语法填空输入；简答、默写自评。全部小题交卷后逐题给分，主观小题自评完给出本篇得分。
- **自评**：解答题五档（全对 / 大部分 75% / 一半 / 少量 25% / 不会），小题三档，作文五档（满分档 / 80% / 60% / 35% / 0）。不做文字输入判分的：语文简答、默写，英语作文。
- **分值**：先读原卷（大题标题“每小题 x 分”、题干“（13 分）”、“选对但不全的得 x 分”），否则按新高考常见卷面（数学 5 / 6 / 5 / 15，竞赛一试填空 8、解答 20、加试 45；物理 4 / 5（不全 3）/ 实验 8 / 计算 13；化学 3 / 14；生物 2 / 4 / 12；英语阅读 2.5、完形 1、语法填空 1.5、应用文 15、读后续写 25；语文选择 3、翻译 8、作文 60）。
- 没拿满分的题进错题本（`piggy2-study-wrong`，最多 400 条）；错题重练只出错题，答对即移出。最近出过的 600 题记在 `piggy2-study-recent`，挑题时排在后面。
- 键盘：1–8 / A–H 选中选项，Enter 交卷、看答案或下一题；输入框里 Enter 跳到下一空或交卷。

## 题库格式

一套卷一个 UTF-8 JSON 文件，`format` 为 `piggy-study-bank`。文件头依次是 `format / version / id / title / subject / subjectName / source / built / count`，游戏列表时只读前 4 KB。游戏读取 `version` 1 和 2。

```
{ "format":"piggy-study-bank", "version":2, "id":"…", "title":"…", "subject":"math|physics|chem|bio|chinese|english",
  "subjectName":"英语", "count":9, "macros":{"\\foo":"…"},
  "units":[{"name":"…","questions":[
     {"id":"…","no":1,"type":"single|multi|blank|solve","part":"一、选择题…","title":"考点","stem":"<html>",
      "options":["<html>",…],"answer":"B | ABD | <html>","solution":"<html>",
      // 可选：points、level(1–3)、kind
      // 第 2 版整篇题组：
      "grouped":true,"sourceNos":[56,57,…],"shared":["<html>",…],
      "subs":[{"no":56,"type":"single|multi|blank|solve|pick","stem":"<html>","options":["<html>"],"shared":true,
               "answer":"B | 单词/另一写法 | <html>","picks":["A",…,"H"],"points":1.5}]}]}],
  "figures":{"id":{"src":"data:image/webp;base64,…","w":300,"h":180}} }
```

- 题面、选项、解析是受限 HTML：行内公式 `<span class="sx-m">LaTeX</span>`，行间公式 `<div class="sx-dm">LaTeX</div>`，题图 `<img class="sx-fig" data-fig="id">`，栏目框 `<div class="sx-box …">`。
- 载入时 `study-core.js` 检查格式、题型、答案字母与选项个数（含小题与公共选项）、题图必须是 data:image、宏名必须是 `\\` 加字母；`study-ui.js` 再按标签与属性白名单清洗 HTML，题图只用题库自带的数据。

## 题库放在哪里

| 版本 | 位置 | 怎么放 |
|---|---|---|
| Windows 便携版 | exe 旁边的 `猪猪题库/`（两层以内的 .json） | 直接复制文件夹；或游戏内“导入题库文件” |
| 安卓 | 应用内部 `files/study/` | 游戏内“导入题库文件”，系统文件选择器可多选 |
| 单文件网页 / 旧 Windows 壳 | 浏览器 IndexedDB `piggy-study` | “导入题库文件”或“导入整个文件夹” |

桌面壳只开放 `PiggyStudy.dir / list / head / read / importFiles / openFolder`，读取路径限定在题库文件夹内；安卓 `PiggyStudyAndroid` 只开放 `list / head / read / remove / pick`。题库只在本机读取，不联网。题库包含试卷原文与解析，属于使用者的个人资料，不在本仓库，也不作为发行附件。
