# 4.4.4：版本调整与正式发行

2026-10-16 按用户要求将临时编号 4.5.1 改为正式版本 **4.4.4**。保留全部 20 款游戏和猪猪跳一跳玩法，未新增美术、模型或音效。

## 安卓自动更新

已发行 [安卓 4.4.4 APK](https://github.com/tzlh6/piggy-playground/releases/tag/v4.4.4-android)，并从实际上传、重新下载核验的 APK 生成 `android/update.json`。4.4.2 / 4.4.3 支持启动自动检查，也可在「游戏大厅 → 版本与更新」手动检查，点下载后由安卓系统确认安装。自动检查默认打开，可以关闭；它不会自动确认系统安装。

包名与发行签名不变，覆盖安装保留应用数据，不要先卸载。显示版本为 4.4.4，内部 `versionCode` 提高到 40502，因此也可覆盖临时 4.5.1（40501）。未来编号继续递增，不再从显示版本机械换算。4.4.1 的手动按钮有旧接口问题，4.2 无更新功能，需手动覆盖安装一次。没有手机真机安装验收。

## Windows 改号兼容

[Windows 4.4.4](https://github.com/tzlh6/piggy-playground/releases/tag/v4.4.4) 修正临时 4.5.1 的内容排序：旧缓存不会覆盖内置 4.4.4，也不会遮住后续 4.4.5；程序兼容版本仍按通常数值比较。`minShell` 提高至 4.4.4，因此旧程序需换新版 EXE 一次。把 EXE 放在原文件夹，保留旁边的「猪猪游乐场存档」。未对真实玩家存档进行修改或删除。
