# 4.4.5 · 黑猪8

> 后续4.4.6已将猪叫换回四只猪的既有录音，见[原声修正](4.4.6-pool-voices.md)。本页保留4.4.5开发记录与玩法。

第 21 款游戏是猪猪主题八球台球，可离线玩。包含三档人机、同屏双人和自由练球。

球改为圆滚滚猪仔：大鼻子、卷尾、短蹄、会甩动的耳朵；8 号黑猪戴小皇冠。两位玩家为奶桃侦探桃桃和芋泥海盗乌梅，配色、服装、持杆姿势与出杆动作不同。球袋是猪耳造型，库点是小猪蹄印。复用 PigArt，新增球桌与猪仔球用程序绘制，无外部美术或新增录音依赖。

移动鼠标或点桌面瞄准，沿反方向拉杆后松手出杆；可用力度条、出杆按钮或空格。轻点桌面不误击球；暂停、弹窗、切出与触摸取消会清除未释放的操作。完整辅助显示幽灵白猪、首个碰撞、目标球初始方向与白猪切线，可改短线或关闭。手机自动竖桌，数字保持正向；“专注球桌”收起大厅与说明，保留操作区。

每次有效球碰球或碰库都有短合成猪叫，按冲量改变轻重，左右位置影响猪叫声像；清脆击球、库边闷声、入袋咕咚分层合成。猪叫 / 提示声跟随声音工坊各自音量和三种音色。挤扁回弹、眯眼张嘴、耳尾晃动、碰撞粒子、轻震屏和入袋缩落不改变物理；“减少动态效果”会收敛演出。

## 休闲八球规则

- 开球至少进一颗彩猪或使四颗彩猪碰库。开球后仍开放；之后首次合法进球按第一颗实际进袋彩猪分组。1–7 实色，9–15 花色。
- 先碰本组；合法进本组续杆。只进对手球不单独算犯规，但不续杆。碰球后须有目标球进袋或任意球碰库。
- 白猪落袋、先碰错球、未碰球或碰后没进袋 / 碰库，给对方桌面自由球。避开其他球、库边和袋口；不限开球线。
- 出杆前已清完本组，才能打黑猪。先指定 1–6 号袋，黑猪入该袋获胜；提前进、进错袋或同杆犯规判负。同杆最后一颗本组球与黑猪一同进仍判提前进。
- 开球进黑猪会摆回，其他进球保留；有犯规则对方自由球。普通彩猪不需报袋。
- 自由练球不分组、不判负，任意顺序清十五颗；白猪落袋后重新摆。五个模式分别保存最多进球。
