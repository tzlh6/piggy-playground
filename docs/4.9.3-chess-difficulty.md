# 4.9.3 国际象棋分档

国际象棋改为一个难度菜单，默认“萌新陪练”。第一次使用本版会选中最轻松的一档，之后记住所选难度；既有 Elo 数值、对局和成绩不删除。切换人机难度保留当前棋局，取消旧搜索，从电脑下一步生效；切换同屏双人会新开一局。

| 档次 | 对手设置 |
| --- | --- |
| 萌新陪练 | 简单一层判断，80% 的回合从合法着法中随机选择，会漏吃子与漏防守 |
| 轻松入门 | 简单两层判断，45% 的回合从合法着法中随机选择 |
| 休闲练习 | Stockfish 目标 Elo 1320，初始推荐快想 |
| 认真对弈 | 目标 Elo 1600，初始推荐标准 |
| 进阶挑战 | 目标 Elo 2000，初始推荐标准 |
| 高手过招 | 目标 Elo 2400，初始推荐深思，直接展开 Elo 滑块 |
| 大师挑战 | 目标 Elo 2800，初始推荐深思，直接展开 Elo 滑块 |
| 极限挑战 | 保留最高目标 Elo 3190，初始推荐深思，直接展开 Elo 滑块 |

前两档为自有规则核心的宽松陪练，不标注未经测定的 Elo。搜索预算分别为约 90/180 毫秒；浅层判断包含吃子等必要延伸。提示不主动随机漏招。其余档次沿用 Stockfish 19 Lite、每次搜索先开启限强再设置 Elo 的机制。Elo 是引擎练习目标，不能直接视为真人等级分。

工具栏的“自定义棋力”保留 1320–3190 的滑块和数字输入，高手/大师/极限三档默认展开。修改 Elo 会切换到“自定义棋力”，保留棋盘；预设不会覆盖之前保存的自定义 Elo。

使用 Stockfish 的档次均可独立选择快想 0.6 秒、标准 1.6 秒、深思 3.2 秒、长考 10 秒、充分思考 30 秒或不限时。时间选择保存后沿用，不随换档重置。有限时间使用 `go movetime`，移除原来的 8/15/26 层人为上限；不限时使用 `go infinite`，没有搜索超时定时器，持续迭代加深。界面显示当前深度和搜索局面数，点“让它落子”或“查看当前提示”发送 `stop`，采用引擎正式返回的当前结果。重开、悔棋、换档、调整时间/Elo或离开会终止旧任务。国际象棋无法保证算完全部变化，不能把“不限时”解释成保证搜完棋局。

其他棋类保持原来的时间和深度限制。

本版增加专门的分档测试，检查最高配置、宽松策略、合法着法、提示与存档；界面需核对新默认值、升级后首次进入、八档切换、思考中切换、保存、自定义与同屏双人。验证结果和本地安装包状态以交付记录为准。
