# 4.8.0 装扮版

猪猪换装新增六种配色和十种小装饰，Windows、离线网页与安卓统一更新至 4.8.0，保留 23 款离线小游戏。

- 六种新配色：白巧克力、黑巧克力、抹茶麻薯、柠檬汽水、焦糖拿铁、奶牛花花；连同原有配色共十种，包含 130 个造型 SVG。
- 十种小装饰：铃铛项圈、小领结、珍珠项链、尾巴蝴蝶结、耳边小花、爱心腮红、小雀斑、绅士胡子、天使翅膀、亮晶晶，可与原有服饰叠戴，也可选“不戴”。
- 点击右上角“猪猪换装”选择配色和装饰，关闭窗口即保存；各个游戏中的自己的小猪同步换装。电脑对手与老师不会戴玩家的装饰。
- 黑巧克力猪猪的眼睛、眉毛与胡子使用浅色；白巧克力和奶牛花花保留清楚的轮廓。
- 斗地猪新版玩家的联机头像携带各自的配色与装饰；旧版客户端遇到不认识的配色会回退为奶桃团子。

Windows 最低外壳版本仍为 4.7.1，现有 4.7.x 程序可在线更新游戏内容。新下载者使用 Windows EXE，离线网页下载 HTML 后用浏览器打开；请保留 EXE 旁原有存档目录。

安卓普通包为 PiggyPlayground-4.8.0-Android.apk（40810）；旧更新器兼容包为 PiggyPlayground-4.8.0-Android-compat.apk（40800），供旧通道自动选择。通常只下载普通包，无需同时安装两个包。沿用原签名，nativeRevision=5，覆盖安装保留题库、成绩与设置，请不要先卸载。最低 Android 8.0。
