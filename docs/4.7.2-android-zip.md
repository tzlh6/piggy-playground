# 安卓 4.7.2：ZIP 一次导入题库

猪猪爱学习支持直接选择 ZIP 压缩包，一次导入其中全部学科的 JSON 题库，无需提前解压或逐个选文件。支持压缩包里的分学科子文件夹，题图、答案和解析随题库保留；也可继续导入单个或多个 JSON 文件。题库仍由使用者自行准备。

覆盖安装新版后，打开「猪猪爱学习 → 导入题库文件」，选择一个未加密的 `.zip` 即可。已有题库、成绩和设置会保留；同名题库覆盖更新，其他题库保留。普通用户只安装普通包，不要先卸载。

这是安卓独立原生补丁，共用游戏、Windows 与离线网页保持 4.7.1。普通包 `PiggyPlayground-4.7.2-Android.apk`（40712），旧更新器兼容包 `PiggyPlayground-4.7.2-Android-compat.apk`（40702），原生修订号 5，沿用原签名；下一版普通编号从 40713 起。两种 APK 的游戏内容和原生代码相同。

ZIP 导入先在应用私有缓存验证全部成员，再保存题库。说明和其他非 JSON 文件跳过，压缩包路径不会直接写入文件系统；损坏或加密压缩包会提示错误。读取限制覆盖单文件、压缩输入、解压总量和成员数量。JSON 也会检查题库格式、版本和题目单元，保存时使用原子替换。

主机测试覆盖普通 JSON、嵌套目录、UTF-8 与中文 Windows 文件名、无关文件、路径越界、空包、损坏、截断、加密、大小及数量边界，并用真实六科资料检查文件内容与题数。APK 已检查版本、原签名和内置网页；手机视口模拟原生桥验证导入、重复导入与出题。安卓真机安装和系统文件选择器仍待设备验证。

ZIP 测试命令：`python android/tools/test-study-import.py --jdk <JDK目录>`。构建沿用 `android/build.py`；从实际发行 APK 生成双通道清单时显式指定 `--native-revision 5`。
