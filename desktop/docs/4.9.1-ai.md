# 4.9.1 人机强度升级

国际象棋、中国象棋、自由五子棋、黑白棋接入四套独立离线引擎；四子棋、围栏、海战、轮盘、斗地猪与黑猪8同步增强。共29款游戏，原有规则、成绩和存档格式保持兼容。

## 四套引擎

| 游戏 | 固定构建与来源 | 许可 |
| --- | --- | --- |
| 国际象棋 | [Stockfish.js 19.0.1](https://github.com/nmrugg/stockfish.js/releases/tag/v19.0.1)，Lite 单线程 | GPL-3.0 |
| 中国象棋 | [Pikafish-wasm 2023-03-05](https://github.com/ousc/Pikafish-wasm/releases/tag/Pikafish-2023-03-05)，单线程 SIMD128 NNUE | GPL-3.0 |
| 自由五子棋 | [Rapfi](https://github.com/dotb1ue/rapfi)，0.43.02 / 3aedf3a；[固定 Web 构建](https://github.com/CyanXLab/GomokuAI/tree/822be514c7fa563ed2a735628cb60868b913c792/public/build) | 程序 GPL-3.0；[网络](https://github.com/dotb1ue/rapfi-networks) CC0 |
| 黑白棋 | [Egaroucid for Web](https://github.com/Nyanyan/Egaroucid/tree/67aa89f18bfd22fa35730cdc0a9f4e7501c2239a/docs/en/web)，官方固定 Web 构建 | GPL-3.0 |

完整来源、下载地址、压缩包成员、SHA-256 和变换过程见 `tools/engine-upstreams.json`、`tools/vendor-engines.py`。皮卡鱼采用兼容离线环境且有对应源码的固定构建。源码及许可也可从程序“关于”中查看。

所有计算在本地后台线程完成，程序包含 WASM 与所需神经网络。入门、聪明、高手分别给予约0.6、1.6、3.2秒搜索预算，并限制不同深度；首次运行还需加载和初始化。黑白棋逐级搜索，在预算内采用最后完成的结果。提示使用相同引擎。重开、悔棋和离开游戏会取消旧任务，回复按对局标识核验。设备无法运行时使用增强后的兼容搜索。

单线程构建适配本地文件、单文件网页、安卓 WebView 与旧版 Windows 程序内核；不要求跨源隔离或网络请求。五子棋使用自由五子网络；精确五子规则等其他配置由兼容核心处理。象棋的休闲重复裁决仍以游戏规则核心为准。

## 其余对手

- 四子棋：强制威胁、迭代搜索和局面缓存，取消随机放水。
- 围栏：连续收格、出牌权变化、避免送出第三条边、小残局精确搜索。
- 海战：三档均按公开命中、落空和击沉信息推算；高档在小残局枚举相容舰队，并从更多候选布局中挑选较难被搜索的布舰。布舰是可回放的完整操作。
- 轮盘：低档也认真记数和使用道具；聪明档推演连续行动，恶魔档加入对手应对；仅使用公开记录及自己的线索。
- 斗地猪：取消低档随机失误，加强记牌、农民配合和候选筛选；后段抽样推演，满足规模限制的小残局枚举可能发牌并进行团队搜索。不会读取对手真实手牌。
- 黑猪8：降低瞄准误差；用同一物理系统模拟多个目标、力度和自由球位置，考虑进球、白猪落袋、提前打进黑猪和碰库解球。

## 构建、验证与边界

`npm test` 包含18组回归；新增 `test-ai.cjs` 检查战术、独立穷举残局、隐藏信息、布舰事务和搜索状态恢复；`test-engine-packs.cjs` 检查离线数据、WASM、摘要、许可及更新器大小限制。长期随机压力对局可用 `PIGGY_AI_STRESS=1` 启用。不用未经配对的随机发牌胜率作棋力证明。

四套引擎已在现代 Chromium 和 Windows 程序的 Chromium 108 中实际给出合法着法；离线网页检查了连续走子、历史局面、将死、取消后重新搜索，无远程请求。另检查实际界面落子、提示、悔棋与重开/切换取消。安卓双包同原签名、内置网页一致，普通 versionCode=40911，兼容=40901，nativeRevision=5。Windows 最低外壳版本仍为4.7.1。

引擎和模型使安装包体积增加。首次准备时间与实际搜索深度取决于设备；没有对安卓真机、Windows 7实机或正式赛事等级进行测定。
