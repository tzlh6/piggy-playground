# 猪猪夺宝后端验证记录

日期：2026-10-13。规则版本：`1.0.0`。运行环境：Windows、本地 Node.js 24.19.0 与 Python 3。验证对象是离线规则后端；前端尚未接入。

## 已通过

- 原有十组检查全部通过：基础游戏、音效、街机、新游戏、挑战、轮盘、单击操作、斗地猪、斗地猪房间、局域网中继。未修改旧游戏规则或界面。
- `node test-heist.cjs` 最终通过 145735 项计数检查，含 90 局固定种子随机完整对局、9 局不同人数和电脑策略的完整对局。随机局覆盖 4028 次行动、690 次爆炸、339 次弹簧、199 次传送、175 次掉落、111 次推撞与 14 次连锁保护。
- 覆盖非法命令不改变状态、过期指令拒绝、快照隔离、预览与实际结果相同、重放和撤销、松露守恒、行动点与炸弹库存、整轮判胜、家门和闸门保护。额外修复并回归验证：同波爆炸的先前连锁把猪送回家后，后续锁定命中不能再把它炸出家门。
- 用独立三人收益树检验 MaxN 的逐玩家收益选择；节点预算用尽时丢弃未完成搜索层。电脑行动合法、节点数受限、同一快照选择可复现。
- 用 Node VM 核对浏览器模块加载与 Worker 消息格式；核对请求号、局号和修订号透传。这是协议检查，不是浏览器或安卓实机测试。
- 当前 19 款游戏的单文件构建通过，完整 Apache-2.0 许可成功内嵌且没有外部脚本标签。该构建仅供本地核验，不作为新版本成品；夺宝界面尚未纳入。

## 对打基准及其限制

`node tools/benchmark-heist.cjs docs/heist/benchmark-results.json` 完成 18 场。每种人数分别比较全 `smart` 和“座位 0 使用 `devil`，其余为 `smart`”，轮换全部先手。原始积分、动作和耗时保存在同目录 JSON 中。

| 人数 | 座位 0 使用深度搜索时获胜场数 | 场数 |
|---|---:|---:|
| 2 | 1 | 2 |
| 3 | 1 | 3 |
| 4 | 1 | 4 |

这些是固定地图与确定性策略下的对局次数，不是统计胜率。深度搜索尚未表现出稳定强于 `smart` 的证据。全 `smart` 的双人局均由先手获胜，四人局也出现明显座位偏向，应继续检验路线估值、方向排序和地图资源分配；不能仅凭几何对称宣布公平。基准与回归曾并行运行，耗时会受机器负载影响，不能用来承诺手机帧率。

当前自动策略很少主动旋转弹簧，较少使用炸弹，尚不足以证明战术多样性或玩家感受到的难度。默认电脑建议 `smart`；深度搜索在前端标为实验选项，待真人试玩和有针对性的策略调整后再决定正式难度名称。
