# 猪猪游乐场 5.1.0

| 游戏 | 玩法 |
|---|---|
| 猪猪水管工 | 旋转 4×4、5×5 或 6×6 管道棋盘。水从粉色水泵出发，全部格子连通且无漏口即获胜。每局生成一棵连通树再打乱方向。可撤销、提示，提示局单独结算。 |
| 猪猪数字画 | 按行列数字涂色并打叉。每个数字表示一段连续涂色，段与段之间至少有一个空格。5×5、7×7 和 9×9 各三幅原创图案。 |
| 猪猪过河 | 用方向键、WASD 或屏幕按钮移动一格。躲车、乘木筏过河，送四只猪仔各回一间空猪舍。三条命，难度影响车辆、木筏速度及每趟时间。 |

## 修复与验证

- 扫猪保留所选难度，方向键在行列边界停下；未知或保留字链接回到大厅默认游戏。
- 游戏结算独立于音效，静音或打开说明仍会结算。换游戏或重开会取消上一局尚未显示的结算。
- 跳跳猪释放指针、切出窗口时清理按住状态。焦点在按钮上时，Enter 和空格可以正常激活按钮。
- 窄屏网页保留分类和排序入口，贪吃猪显示完整草地。安卓局域网的 R / P 快捷键遵守联机界面控制状态。
- 安卓生成阶段先构建精简页面，再用校验通过的页面替换 APK 资产。四套棋类引擎按需加载。

`node test-meadow.cjs` 验证 360 张随机水管图有解、九幅数字画各有唯一解，并覆盖过河的车辆、木筏、超时、生命和重复猪舍判定。
