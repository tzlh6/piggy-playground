# 4.9.2 国际象棋可调Elo

进入“棋类 → 猪猪国际象棋”，在棋盘上方的“目标Elo”区域拖动滑块，或直接输入整数。范围1320–3190，首次默认1500；选择自动保存，切换思考档、重开和再次启动都会保留。同屏双人隐藏人机控件。

快想、标准、深思分别给予约0.6、1.6、3.2秒搜索预算。Elo选择和思考时间分别控制目标棋力与搜索预算；提示沿用当前Elo。思考中调整时取消旧请求，以当前棋局重新计算，不修改已经走出的棋。

## 引擎设置

本程序固定的Stockfish 19 Lite实际返回：

```
option name UCI_LimitStrength type check default false
option name UCI_Elo type spin default 1320 min 1320 max 3190
```

每次实际搜索都依次发送并等待：

```js
await command('setoption name UCI_LimitStrength value true');
await command('setoption name UCI_Elo value ' + job.elo);
```

之后才发送棋局和搜索命令。引擎复用时也重新设置，避免沿用上一档数值。输入会校验、取整和限制范围；空输入保留原值。若引擎没有声明对应选项，不会静默执行不受限搜索；启用兼容策略时会说明Elo未生效。

Elo为引擎练习目标，表现还受设备、时间和局面影响，不表示经过真人对局测定的等级分。[Stockfish说明](https://official-stockfish.github.io/docs/stockfish-wiki/Stockfish-FAQ.html)解释了限强机制。
