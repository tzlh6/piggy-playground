你的小小游乐场

18 款游戏，全部离线，鼠标单击或触屏点按就能玩完每一款。成绩、猪猪造型和声音设置自动保存在本机。切换游戏会开始新局；切出窗口自动暂停。快捷键：R 重新开始，P 暂停，M 静音。每款游戏下方都有具体玩法，侧栏可以搜索游戏。

扫猪：左键翻格、右键标旗，F 键切换标记模式；数字周围旗数吻合时，点数字连开（按住数字可预览周围格）。踩到猪时，其余小猪会像 Windows 扫雷一样一个接一个炸醒。猪猪 2048：方向键 / WASD / 滑动 / 屏幕方向按钮，相同的小猪合在一起会长大一级。贪吃猪：方向键 / WASD / 滑动转向。跳跳猪：空格、↑ 或点击跳（空中可再跳一次），↓ 趴下。翻牌与捉迷藏：点击即可。

猪猪轮盘：真屎、假屎的数量公开、顺序隐藏。对自己打出假屎不扣血还能继续；打出真屎扣血并换手；对对手开枪无论真假都换手。六件道具都不结束回合：魔法书看下一发、X 光任选位置、饲料让下一发真屎×2（强化跟着枪走）、肉回一滴血、泥巴跳过对手下一回合、马桶搋子吸出当前一发。三局两胜，每局 4 滴血。只用鼠标：点背包里的道具、点中间的大按钮开枪；用 X 光时再点一个未知位置。

只用鼠标 / 触屏：每款游戏都有屏幕按钮。跳跳猪点“趴下”会低头一会儿；切切猪点一下也能切；星际守卫点哪飞哪；节奏派对默认“单击模式”，长条点一下即可、双键点一个即可（可在工具栏关闭）。

桌面便携版优先在 exe 同目录的「猪猪游乐场存档」保存记录。拷贝 exe 和这个文件夹即可带走成绩；目录不可写时保存在当前电脑。
