# Windows与通用网页源码 · 4.9.4

象棋与国际象棋改为“帅帐对弈”：两只军师猪站在棋盘两侧指点，将死时播放以猪为主角的完整动画（[说明](docs/mate-recognition.md#军师猪绝杀动画)）。

国际象棋八档难度，默认萌新陪练，保留最高目标Elo 3190及滑块。思考可选0.6/1.6/3.2/10/30秒或不限时，显示深度并支持手动落子，无人为深度上限。[说明](docs/4.9.3-chess-difficulty.md)。

`npm test`执行21组检查。`npm ci`安装依赖，`npm run build:win`生成Windows便携版，`npm run build:web`生成单文件网页。最低外壳仍为4.7.1。Elo为练习目标；不限时不保证穷尽国际象棋。四套独立引擎、GPL-3.0/CC0许可和来源随程序保留。
