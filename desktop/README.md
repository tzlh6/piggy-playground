# Windows 与通用网页源码 · 5.1.0

共 32 款离线游戏。本版新增猪猪水管工、猪猪数字画、猪猪过河。三款支持键盘、鼠标和触屏操作。规则与上游出处见 [5.1.0 说明](docs/5.1.0-meadow.md)。

象棋与国际象棋改为“帅帐对弈”：两只军师猪站在棋盘两侧指点，将死时播放以猪为主角的完整动画（[说明](docs/mate-recognition.md#军师猪绝杀动画)）。

国际象棋八档难度，默认萌新陪练，保留最高目标Elo 3190及滑块。思考可选0.6/1.6/3.2/10/30秒或不限时，显示深度并支持手动落子，无人为深度上限。[说明](docs/4.9.3-chess-difficulty.md)。

`npm test` 执行 22 组检查。`npm ci` 安装依赖，`npm run build:win` 生成 Windows 便携版，`npm run build:web` 生成单文件网页。Elo 为练习目标，四套独立引擎及其 GPL-3.0/CC0 许可和来源随程序保留。
