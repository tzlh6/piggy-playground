# 安卓 4.10.0：启动修复与中国象棋学堂

本版仅升级手机端。安卓显示版本 4.10.0，普通包 41010，旧更新器兼容包 41000，nativeRevision=6；共用游戏内容仍为 4.9.4，Windows 与离线网页保留 4.9.4。

## 启动问题与修复

用户反馈：荣耀80GT、安卓15，点4.9.4图标后立即退出，4.4.0可以打开。未取得该手机的崩溃日志，因此不能把桌面测试等同于荣耀实机复现。

发现的启动内存风险：旧MainActivity把约48.5MB的HTML读入ByteArrayOutputStream，再复制为字节数组、转换为String，随后交给WebView。页面中约44.7MB是四套棋类引擎的内联数据。相同读取代码在128MiB Java堆中复现OutOfMemoryError。

修复分为两部分：

- 用固定HTTPS虚拟来源的资源拦截器直接流式返回APK内容，入口改为loadUrl，避免整页复制进Activity的Java堆。
- 启动页移除四套引擎的内联数据，改用现有按需分片加载。首页约3.84MB，44份引擎分片仍在APK内，游戏继续支持离线。

保持 `https://appassets.androidplatform.net/` 来源、包名及原签名。没有修改文件访问权限或开放外部网页；只允许打包的入口和固定引擎分片，其他HTTP(S)请求继续阻断。路径测试覆盖伪造主机、编码路径、目录穿越、用户信息、异常端口和私人题库路径。

设计依据：[Android本地内容加载](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content)、[WebView内存管理](https://developer.android.com/develop/ui/views/layout/webapps/manage-webview-memory)。本项目实现轻量的固定资源白名单，不新增AndroidX依赖。

## 中国象棋教学

入口在手机游戏大厅的“象棋学堂”，以及中国象棋页顶的同名按钮。国际象棋未新增教学入口。

- **AI教练**：从当前中国象棋对局取教学副本，或从标准初始局面试走。用皮卡鱼MultiPV比较最多三个候选，给出真实搜索分数、深度和合法主变化，解释将军、吃子、回吃及出子意图。分数统一为当前行棋方视角。
- **杀招闯关**：10道练习，覆盖重炮、马后炮、天地炮、铁门栓、双车错和对应黑方视角。可提示、重练、翻转及演示。自行完成才计入学习进度；演示不代替通关。即刻将死的其他合法答案也接受，多步题按本题收网路线练习。
- **棋谱研习**：中炮对屏风马、飞相布局、仙人指路三份入门示范，每步配原创说明。支持前进、后退、演示、导入和复制ICCS棋谱。导入支持可选的PGN Event/FEN头，逐手验证，最多500手；并非所有商业棋谱格式的通用导入器。
- 教学棋盘独立于原对局，不自动代走，不改原局面或胜场。关闭、切换学习方式、后台或停止分析时取消过期搜索。分析在独立Worker中运行，使用单线程和16MB Hash预算。

- [xiangqi.js](https://github.com/lengyanyu258/xiangqi.js)：成熟中国象棋规则与局面校验库，项目固定提交f9019ac2303d4b80ef0b82fd0515bfb55a80a62b，BSD-2-Clause。教学走法、导入棋谱和引擎变化都经规则库验证。

## 重建与核验

先运行 `python android/build.py --prepare-only`，再运行 `node android/tests/test-xiangqi-school.cjs`。原生白名单检查：`python android/tools/test-offline-assets.py --jdk <JDK目录>`。原有题库导入及更新策略检查继续保留。

APK用原签名构建。发布后生成普通与兼容两份清单，均显式传入 `--native-revision 6`；兼容包额外传 `--legacy`。清单生成工具现在检查整个assets集合，包含全部按需引擎分片。

已进行主机端受限内存测试、原生规则单元测试、390px触控界面真实操作、10道完整练习、三份棋谱和真实皮卡鱼MultiPV检查。实际荣耀80GT安装、安卓原生WebView启动与升级仍需真机确认；不能以Chromium浏览器检查替代。
